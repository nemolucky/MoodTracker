# Mood Tracker — дневник настроения

## Назначение

Mood Tracker — консольное приложение для ведения дневника настроения.
Приложение позволяет:

* добавлять записи о настроении (дата, оценка 0-10, комментарий);
* просматривать список записей;
* находить записи по дате;
* фильтровать записи по минимальной оценке;
* сортировать записи по оценке;
* вычислять средний балл настроения и его тенденцию;
* вести нескольких пользователей приложения;
* сохранять данные между запусками приложения.

## Целевая аудитория

Люди, которые хотят отслеживать своё эмоциональное состояние и видеть
динамику настроения со временем.

## Предметная область

Основными сущностями предметной области являются:

* пользователь;
* запись о настроении.

Пользователь создаёт записи о своём настроении. Каждая запись связана
с конкретным пользователем.

## Основные сущности

### User — пользователь

Объект `User` представляет пользователя системы.

Основные атрибуты:

* `id` — уникальный идентификатор пользователя;
* `name` — имя пользователя;
* `email` — адрес электронной почты (необязательный).

Основные методы:

* `__str__()` — строковое представление пользователя;
* `from_data()` — создание объекта `User` из словаря данных (classmethod),
  используется при загрузке пользователей из JSON.

### MoodEntry — запись настроения

Объект `MoodEntry` представляет запись о настроении пользователя
за определённый день.

Основные атрибуты:

* `id` — уникальный идентификатор записи;
* `entry_date` — дата записи;
* `score` — оценка настроения (0-10);
* `comment` — комментарий пользователя;
* `user` — объект `User`, которому принадлежит запись.

Основные методы:

* `get_status()` — текстовая оценка дня («Хороший день» / «Нейтральный
  день» / «Плохой день») по баллу конкретной записи;
* `__str__()` — строковое представление записи;
* `validate_score()` — проверка корректности оценки настроения (0-10),
  реализована как `@staticmethod`, поскольку не использует данные
  конкретного объекта.

## Взаимодействие объектов

Объект `MoodEntry` хранит ссылку на объект `User`, а не только его
идентификатор:

```
mood_entry
└── user → User
```

Благодаря этому данные пользователя доступны непосредственно через
объект записи:

```python
mood_entry.user.name
mood_entry.user.email
```

## Основные операции

### Работа с записями настроения

* добавление записи (`add_mood_entry`);
* поиск записи по идентификатору (`find_entry_by_id`);
* поиск записей по дате (`find_entries_by_date`);
* фильтрация записей по минимальной оценке (`filter_entries_by_score`);
* сортировка записей по оценке (`sort_entries_by_score`);
* вычисление среднего балла настроения (`get_average_mood`);
* определение тенденции настроения (`get_mood_trend`).

### Работа с пользователями

* добавление пользователя (`add_user`);
* поиск пользователя по идентификатору (`find_user_by_id`);
* поиск пользователя по имени или email (`find_user`).

При добавлении новой записи настроения проверяется, существует ли
указанный пользователь; если нет — создаётся новый объект `User`.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

* `data/users.json`;
* `data/entries.json`.

При загрузке данные из JSON преобразуются в объекты `User` и
`MoodEntry`. При сохранении объекты преобразуются обратно в данные
JSON. Для связи записи с пользователем в `entries.json` используется
идентификатор `user_id`, а не вложенный объект пользователя.

Пример записи в `data/entries.json`:

```json
{
    "id": 1,
    "user_id": 1,
    "entry_date": "2026-09-13",
    "score": 8,
    "comment": "Отличная встреча с друзьями"
}
```

## Назначение модулей

### `main.py`

Точка входа в приложение. Отвечает за:

* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев (просмотр, добавление,
  поиск, фильтрация, сортировка записей и пользователей).

### `models/users.py`

Содержит класс `User` и функции работы с коллекцией пользователей.

### `models/entries.py`

Содержит класс `MoodEntry` и функции работы с коллекцией записей
настроения.

### `storage.py`

Отвечает за загрузку и сохранение данных. Выполняет преобразование:

* JSON → объекты Python (`User`, `MoodEntry`);
* объекты Python → JSON.

### `utils.py`

Содержит вспомогательные функции безопасного ввода:

* `input_int()` — безопасный ввод целого числа;
* `input_date()` — безопасный ввод даты.

### `tests/`

Содержит автоматизированные тесты проекта.

## Запуск приложения

Для запуска выполнить:

```text
python main.py
```

После запуска отобразится главное меню.

## Тестирование

Для запуска автоматизированных тестов выполнить:

```text
pytest -v
```

Тесты проверяют:

* создание и работу объектов `User` и `MoodEntry`;
* методы классов (`get_status()`, `validate_score()`, `from_data()`);
* операции с записями настроения (поиск, фильтрация, сортировка,
  расчёт среднего балла);
* операции с пользователями (добавление, поиск по id, поиск по
  имени/email);
* связь записи настроения с пользователем.
