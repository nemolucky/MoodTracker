# Mood Tracker

Консольное приложение для ведения дневника настроения:
записи со оценкой дня (0-10) и комментарием сохраняются
между запусками в JSON-файле.

## Возможности

- просмотр всех записей настроения;
- добавление новой записи;
- поиск записей по дате;
- вычисление среднего балла и общей тенденции;
- фильтрация записей по минимальной оценке;
- сортировка записей по оценке;
- определение тенденции настроения (улучшается / ухудшается / стабильно).

## Структура проекта

```
mood_tracker/
├── README.md
├── requirements.txt
├── main.py       - точка запуска, меню приложения
├── entries.py    - функции работы с записями настроения
├── storage.py    - сохранение и загрузка данных (JSON)
├── utils.py      - вспомогательные функции безопасного ввода
├── data/
│   └── entries.json
└── tests/
    └── test_entries.py
```

## Формат данных

Файл `data/entries.json` содержит список записей:

```json
[
    {
        "entry_date": "2026-09-13",
        "score": 8,
        "comment": "Отличная встреча с друзьями"
    }
]
```
