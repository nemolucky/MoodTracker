# Система учета настроения

## Назначение
Приложение помогает пользователю фиксировать своё эмоциональное
состояние в течение дня и отслеживать динамику настроения со временем.

## Целевая аудитория
Люди, которые хотят следить за своим эмоциональным состоянием
и выявлять факторы, влияющие на настроение.

## Предметная область
Учёт и анализ личных записей о настроении пользователя.

## Основные сущности
- Пользователь
- Запись настроения (дата, оценка, комментарий)
- Категория/тег настроения

## Основные функции
- Добавление новой записи о настроении
- Вывод статуса дня (хороший/нейтральный/плохой)
- Расчёт среднего настроения за период

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
